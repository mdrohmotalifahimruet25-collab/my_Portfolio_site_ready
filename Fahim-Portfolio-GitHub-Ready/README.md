# Md Rohmot Ali Fahim — Portfolio

A static portfolio website. No build step is required.

## Files

- `index.html` — main portfolio page
- `styles.css` — site styling and responsive layout
- `script.js` — navigation drawer, theme toggle, and footer year
- `learning-guides.js` — interactive learning guides for the focus areas
- `cv.html` — online CV page
- `assets/fahim-profile.jpg` — profile photograph

## Preview locally

Open `index.html` in a browser. Keep all files and the `assets` folder together so the styles, scripts, photo, and CV link work.

## Publish with GitHub and Vercel

1. Extract this folder.
2. Create a new GitHub repository and upload the contents of this folder, keeping `index.html` at the repository root and preserving the `assets` folder.
3. In Vercel, import that GitHub repository.
4. Select the **Other** framework preset if asked. Leave Build Command and Install Command empty; the static site can be deployed directly.
5. Deploy. Later commits pushed to the connected repository can trigger new deployments.
